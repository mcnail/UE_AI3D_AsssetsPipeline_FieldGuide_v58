# 프로젝트 지침 안내

이 프로젝트의 지침 원본은 `Rules/` 폴더에 있는 Markdown 파일이다. 새 작업이나 기존 작업의 연속 작업을 시작할 때 아래 파일의 현재 내용을 읽고 따른다.

- `Rules/00_BASE_DIRECTIVE.md`: 제작 원칙과 기본 작업 흐름
- `Rules/00_FOLDER_RULES.md`: 작업폴더 구성과 파일 이름 규칙
- `Rules/00_SHARED_DESIGN_RULES.md`: 여러 제작 단계에서 사용하는 디자인·컬러링·재질 기준
- 해당 제작 단계의 지침: `Rules/01_PLANNING.md`부터 `Rules/06_MODELING_SHEET.md`까지 필요한 파일

새 채팅이나 세션이라는 이유만으로 새 작업폴더를 만들지 않는다. 기존 작업을 이어갈 때는 해당 작업폴더의 기획문서를 확인하고 같은 폴더에서 계속 작업한다. 이미지 결과물을 확인할 때는 아래 규칙을 반드시 적용한다.

## 이전 대화 이미지 참조 금지

**사용자가 현재 작업에 이전 대화의 이미지를 참고해 달라고 명시적으로 요청하기 전에는 해당 이미지를 절대 참고하지 않는다.** 같은 채팅의 앞선 요청과 다른 채팅·세션에서 첨부하거나 생성한 이미지에 모두 적용한다. 작업을 이어 달라는 요청, 이미지가 대화 맥락에 보이는 상태, 폴더의 사본이나 기획문서에 적힌 경로는 참조 허가로 해석하지 않는다.

이전 대화의 이미지를 찾아 열거나 분석하지 않으며, 기억에 남은 시각적 특징이나 이미지에서 도출한 설명·프롬프트를 우회 참조로 사용하지 않는다. 사용자가 텍스트로 확정한 요구사항은 기획문서에서 확인할 수 있다. 사용자가 참조를 요청하면 지정한 이미지와 목적의 범위에서만 참고한다. 현재 요청에 직접 첨부하거나 지정한 이미지와 현재 요청을 수행하면서 생성한 이미지는 이 요청에서 사용할 수 있다.

사용자가 제작 지침의 수정을 요청하면 `Rules/`의 해당 원본 파일을 직접 수정하고 이후 작업부터 적용한다. 에이전트의 작업 규칙은 이 파일에 둔다.
