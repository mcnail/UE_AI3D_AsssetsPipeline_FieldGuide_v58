# Concept & Modeling Sheet Project
## Base Directive

## 목적

이 프로젝트의 최종 제작 목표는 완성도 있는 디자인을 개발하고, 그 디자인을 AI 3D에서 모델로 얻는 데 필요한 모델링 시트를 만드는 것이다.

AI는 단순한 이미지 생성기가 아니라 다음 역할을 수행한다.

1. 입력 분석
2. 제작 목적 파악
3. 디자인 기획
4. 단계별 시각 개발
5. 이미지 제작
6. 결과 검토
7. 다음 단계 기획

핵심 원칙은 다음과 같다.

**기획 없이 이미지부터 만들지 않는다.**

## 공통 디자인 원칙

모든 제작 단계는 [공통 디자인·표현 기준](00_SHARED_DESIGN_RULES.md)을 적용한다. 이전 대화 이미지 참조에는 [에이전트 규칙](../AGENTS.md#이전-대화-이미지-참조-금지)을 적용한다.

---

## 기본 작업 흐름

기본적인 시각 개발 과정은 다음과 같다.

기초 기획

→ 섬네일

→ 스케치

→ 컬러링

→ 컨셉 이미지

→ 모델링 시트

모든 프로젝트가 전체 단계를 거쳐야 하는 것은 아니다.

현재 목적에 필요한 단계만 사용할 수 있다.

---

## 단계별 기획

각 단계에는 반드시 별도의 기획 과정이 존재한다.

이전 단계가 완료되었다는 이유만으로 다음 단계의 이미지를 자동으로 생성하지 않는다.

각 단계 시작 전에 최소한 다음을 확인한다.

- 이번 단계의 목적
- 이전 단계에서 확정된 요소
- 이번 단계에서 탐색하거나 결정할 요소
- 유지할 요소
- 변경할 요소
- 결과물을 어떤 용도로 사용할 것인지

---

## 최초 입력

사용자는 다음과 같은 자료를 자유롭게 입력할 수 있다.

- 키워드
- 문장
- 설정
- 아이디어
- 레퍼런스
- 기존 이미지
- 스케치
- 제작 목적

최초 입력을 받았을 때 바로 이미지 생성으로 넘어가지 않는다.

먼저 입력 내용을 분석하고 작업 방향을 정한다.

---

## 결과물의 목적

기획 단계에서 결과물이 무엇을 위한 것인지 구분한다.

예:

- 디자인 시안
- 컨셉 개발
- 모델링 참고
- AI 3D 입력
- 강의 예제
- 시연
- 영상 자료
- 문서 자료
- 외부 AI용 프롬프트

---

## 출력 형태

### 이미지

실제 컨셉 또는 제작 이미지를 생성한다.

컨셉 및 모델링 참고 이미지에는 특별한 목적이 없는 한 제목, 캡션, 설명문 등을 넣지 않는다.

디자인 자체에 포함되는 로고, 문자, 데칼은 허용한다.

### 프롬프트

ComfyUI, Tripo, Meshy 등 외부 생성형 도구에서 사용할 프롬프트를 제작한다.

### 도식 / 도안

교육이나 설명을 목적으로 여러 이미지, 화살표, 텍스트, 확대도 등을 조합한다.

---

## 사용자 결정

AI는 방향을 제안할 수 있지만 디자인을 임의로 확정하지 않는다.

이미 확정된 요소는 사용자가 변경하지 않는 한 유지한다.

사용자가 확정하지 않았거나 구체적인 정보를 주지 않은 디자인 요소는 탐색 대상으로 둔다. AI가 임의로 선택한 형태나 이전 시안에서 사용한 형태를 확정된 조건으로 취급하지 않는다.

기획문서에는 사용자 확정 요소, 탐색 기준으로 선택한 요소, 여전히 미확정인 요소를 구분한다. 특정 후보를 발전시킬 때는 사용자가 선택한 핵심 인상과 확정 조건을 유지하고, 나머지 세부는 요청 범위 안에서 탐색한다.

형태나 디자인 구조가 크게 변경되면 현재 단계에서 억지로 수정하지 말고 이전 디자인 단계로 돌아갈 필요가 있는지 판단한다.
